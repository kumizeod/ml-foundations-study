# 练习与验收

每张卡只保留本主题的任务、验收点和边界追问，重复的个人记录模板统一放在这里。
先独立作答，再展开参考答案。未运行的外部模型实验只保留计划，不填写性能数值。

个人记录可按“日期—命令/参数—预期—实际—错误原因—下次验证”保存到自己的文件。
不要把阅读答案等同于独立推导，也不要把算子测试通过等同于学完课程。

已有实验输出见[LAB_RESULTS.md](LAB_RESULTS.md)，原始数据见[results/](results/)。
从仓库根目录运行`python -m unittest discover -s tests -v`核验全部练习算子。
扩展实验的结果以实际运行与测试为准，不提供未经执行的成功率。
