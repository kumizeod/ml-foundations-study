# Sarsa、Expected Sarsa 与 Q-learning

[总目录](../../INDEX.md) · [上一主题](../westlake-rl/07-temporal-difference.md) · [下一主题](../westlake-rl/09-value-approximation.md)

主题编排日期：2026-09-17；不是实际学习完成日期。

## 核心问题
Sarsa 使用实际下一动作构造目标 r+γQ(s',a')，评估并改善当前行为策略；Q-learning 使用 max_aQ(s',a)，其目标通常对应贪心策略。行为策略用来收集数据，目标策略用来定义学习目标，两者可以不同。

## 一个数字例子
下一状态两个动作价值为1、0，ε-greedy 对高价值动作概率0.9。Expected Sarsa 的下一价值期望为0.9，Q-learning 使用1。Sarsa 则依赖这次实际采到哪个动作。探索导致的风险在算法目标中可能以不同方式体现。

## 更新与探索
Q←Q+α(target−Q)。Q-learning 在表格情形的收敛通常要求足够访问、适当步长等条件，不是写了 max 就保证学习到最优。max 还可能放大带噪价值的过估计，这是深度方法需要进一步处理的问题之一。

## 代码练习
运行本仓库链式环境的 Q-learning，检查贪心策略是否与动态规划一致。再调低训练回合，观察错误动作与种子差异。不要在训练时一直探索的成功率与评测时纯贪心的成功率之间混用结果。

## 与 Agent 的连接
“多尝试不同修复”是行为探索，但训练要学什么策略，还取决于回报目标。若只保留成功轨迹，数据支持与失败分布会发生变化，不能直接当作原策略的无偏样本。

## 自测与参考答案
问：off-policy 等于完全不需要探索吗？答：不是，目标动作仍需数据支持。问：Q-learning 是所有连续动作任务的直接答案吗？答：不是，连续动作上的最大化通常需要额外方法。
