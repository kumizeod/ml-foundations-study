# 强化学习综合练习、复现与失败分析

[总目录](../../INDEX.md) · [上一主题](../westlake-rl/13-ppo-extension.md)

主题编排日期：2026-09-28；不是实际学习完成日期。

## 主线回顾
MDP 定义问题，Bellman 方程给出递推关系；动态规划使用模型，MC 与 TD 使用样本；价值近似扩展状态规模，策略梯度与 actor–critic 直接优化策略。每次比较都要说明目标、数据来源与估计方式。

## 已提供的实际代码
5状态链式环境有明确转移与奖励。价值迭代能给出独立参照，Q-learning 通过交互样本学习。运行 `python -m study_labs.rl`，再运行测试，检查学习策略与动态规划是否一致。该小实验不需要 GPU，也不能代表复杂机器人算法的性能。

## 复现实验记录
至少保存环境定义、种子、γ、α、ε、回合数、截断长度与最终策略。训练奖励、评测成功率和 Bellman 残差分别反映不同问题。多种子应报告分布，不只选最好的一个。把失败实验保留下来，记录是探索不足、估计误差还是实现错误。

## 与 Agent 项目的连接
让 coding agent 学会恢复失败之前，先定义可重复环境、独立验收和训练评测隔离。权限故障、工具超时和错误补丁不应全压成同一无解释的失败标签。离线轨迹能否支持新的恢复动作，需要检查覆盖，而不是直接套上 off-policy 名称。

## 后续任务清单
自己完成三种改动：改变时间成本、改变链长、限制探索。预测最优策略和学习速度如何变化，再运行验证。若预测错误，写清模型假设与证据差在哪里。继续读真实框架前，能从日志追踪一次 obs→action→reward→update 的调用链。

## 自测与参考答案
问：小环境通过等于 PPO 已掌握吗？答：不等于，还需理解采样、优势、更新与评测。问：学习笔记可以证明看完所有视频了吗？答：不能，个人观看与作业状态应由实际学习者另行填写。
