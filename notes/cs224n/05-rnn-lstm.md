# RNN 与 LSTM：信息如何沿时间传播

[总目录](../README.md) · [上一主题](../cs224n/04-backprop-and-optimization.md) · [下一主题](../cs224n/06-seq2seq.md)

## 核心问题
RNN 通过 hₜ=f(W_hhₜ₋₁+W_xxₜ+b) 维护状态。每一步复用相同参数，使长度可变化；反向传播也因此会累积多时刻对同一参数的贡献。状态既是记忆，也是压缩瓶颈。

## 数学直觉
远处梯度包含多个雅可比矩阵的乘积。若相关方向持续缩小，梯度消失；持续放大则爆炸。LSTM 引入记忆单元 cₜ=fₜ⊙cₜ₋₁+iₜ⊙gₜ，通过门控制保留与写入。加法路径缓解优化难点，但并不保证无限长记忆，遗忘门长期小于 1 时信息仍会衰减。

## 实现与排错
训练时要区分序列维与 batch 维，重置独立样本之间的隐藏状态。截断反向传播通常要 detach 上一段状态：数值可延续，计算图不无限延伸。padding 的尾部不应覆盖最后一个有效词的状态；变长 batch 要根据长度索引。

## 小实验设计
构造“序列第一个符号决定最后标签”的任务，分别增加序列长度，比较普通 RNN 和门控网络。至少记录多个种子、训练样本量和参数规模，不把某一次失败直接归因于架构。该实验是待执行方案，不是本仓库已经测得的比较结果。

## 与 Agent 的连接
长对话上下文也有信息保留问题。摘要、检索与外部状态是不同记忆机制，不能仅因为模型读了全部日志就假定它会正确利用早期约束。

## 自测与参考答案
问：隐藏状态继续传递等于计算图必须继续吗？答：不等于，可 detach 后继续数值状态。问：门控消除了梯度消失吗？答：缓解而非彻底消除。
