# 张量、条件概率与语言建模的输入输出

[总目录](../../INDEX.md) · [下一主题](../cs224n/02-word-vectors.md)

主题编排日期：2026-07-20；不是实际学习完成日期。

## 核心问题
语言模型接收 token 序列，为下一个 token 输出一个概率分布。先把“理解语言”暂时拆成可以检查的接口：输入整数编号，经过嵌入层得到连续向量，再输出词表大小的分数。分数是 logits，不是概率，也不是词义解释。

设 batch 大小为 B、长度为 T、隐藏维度为 d、词表为 V。输入形状是 B×T，嵌入是 B×T×d，输出 logits 是 B×T×V。训练自回归模型时，把输入向左错位一位得到目标。句子“机器人 抓起 杯子”对应的预测包含“机器人→抓起”和“抓起→杯子”，不能把当前 token 同时作为可见输入与目标而不移位。

## 数学与手算
链式法则给出 p(x₁,…,x_T)=∏ₜp(xₜ|x₍₁:ₜ₋₁₎)。负对数似然把乘积变成和：L=−Σₜlog p(xₜ|上下文)。例如两个目标 token 的概率分别是 0.8、0.5，联合概率是 0.4，总损失约为 0.916；按有效 token 平均则是 0.458。二者不能混着比较。

## 实现与排错
padding 仅用于凑齐形状，不代表真实语言。损失分母应使用有效目标数；长样本和短样本按句平均、按 token 平均是不同权重。检查模型之前先打印一条输入、对应标签、忽略掩码和预测位置。若损失异常低，优先排查标签泄漏与错位，而不是认为模型特别强。

## 与 Coding Agent 的连接
工具调用通常也以序列形式生成，但 token 概率高不等于工具参数满足接口。语法合法、参数合法、命令执行成功、任务完成是四层不同的验证。

## 自测与参考答案
问：为什么输入是整数、梯度还能更新嵌入？答：更新的是整数索引选中的参数行，不是对编号求导。问：平均损失 0.458 对应什么困惑度？答：exp(0.458)≈1.58，但只对同一 tokenization 和评测约定有可比性。
